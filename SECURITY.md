# Security

If you find something in the extension that could harm a user's computer or privacy, please report it privately: on this
repository, open **Security > Report a vulnerability**. Please don't open a public issue for it.

Include what you found and where (file and line, or the steps). The extension runs only inside your browser and makes one
network request, the spoiler-list download described in [PRIVACY.md](PRIVACY.md); anything else is a bug worth reporting.
